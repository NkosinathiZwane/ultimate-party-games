# 🎉 Ultimate Party Games

A collection of interactive party games built with React and Vite, perfect for parties, gatherings, and social events.

## 🎮 Games Included

- **Truths & Dares** - Spinning wheel game with casual/couple modes
- **31 Seconds** - Team-based category challenges
- **6 Seconds** - Lightning-fast challenge game
- **Do or Drink** - Card-based challenge game
- **This or That** - Choice-based debate starter

## ✨ Features

- 🎨 Beautiful animated UI with Framer Motion
- 📱 Fully responsive design (mobile & desktop)
- ⏱️ Built-in timers and scoring systems
- 👥 Team and player management
- 🔞 Age verification system
- 🌈 Gradient backgrounds and hover effects
